# Виджет банковских операций

**Статус проекта:** В разработке

## Описание проекта

Разрабатываю новую фичу для личного кабинета клиента банка — виджет на Python, который показывает несколько последних успешных банковских операций клиента.

Проект создан и управляется с помощью **Poetry**, конфигурация описана в файле `pyproject.toml`.

## Структура проекта

Проект состоит из трех основных модулей, каждый из которых отвечает за свою зону ответственности:

### 1. Модуль masks
Содержит две функции для маскирования финансовых данных.

### 2. Модуль widget
Модуль содержит функции для работы с данными, поступающими от пользователя (определение типа счета/карты и форматирование даты).

### 3. Модуль processing
Содержит две функции для обработки списков банковских операций (словарей).

## Тестирование

Проект полностью покрыт тестами. **Покрытие кода составляет 100%** — все модули и функции протестированы и работают успешно.

Для написания и запуска тестов используется фреймворк **`pytest`**. 

В процессе разработки тестов активно применяются лучшие практики:
- **Фикстуры (`fixtures`)** — для создания наборов входных и ожидаемых данных.
- **Параметризация (`@pytest.mark.parametrize`)** — для проверки множества сценариев без дублирования кода.
- **Проверка исключений (`pytest.raises`)** — для гарантии корректной обработки невалидных данных и граничных случаев.

### Структура тестов

Тесты организованы в директории `tests/` и логически разделены по тестируемым модулям проекта:

```text
tests/
├── conftest.py          # Общие фикстуры, доступные для всех тестов
├── test_masks.py        # Тесты модуля masks (маскирование карт и счетов)
├── test_widget.py       # Тесты модуля widget (определение типа и форматирование даты)
└── test_processing.py   # Тесты модуля processing (фильтрация и сортировка операций)
