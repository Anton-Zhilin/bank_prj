# Виджет банковских операций

**Статус проекта:** В разработке

## Описание проекта

Разрабатываю новую фичу для личного кабинета клиента банка — виджет на Python, 
который показывает несколько последних успешных банковских операций клиента.

Проект создан и управляется с помощью **Poetry**, конфигурация описана в файле `pyproject.toml`.

---

## Установка

1. Убедитесь, что у вас установлен Python 3.8+ и Poetry
2. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:Anton-Zhilin/bank_prj.git
3. Установите зависимости с помощью Poetry:
   ```bash
   poetry install
4. В файле .env.example указаны названия всех переменных, необходимых для работы приложения.

## Структура проекта

Проект состоит из 8 основных модулей, каждый из которых отвечает за свою зону ответственности:

```text
src/
├── decorators.py        
├── external_api.py
├── file_readers.py
├── generators.py 
├── masks.py  
├── processing.py 
├── utils.py 
└── widget.py
```

### 1. Модуль masks
Содержит две функции для маскирования финансовых данных.

### 2. Модуль widget
Модуль содержит функции для работы с данными, поступающими от пользователя.

### 3. Модуль processing
Содержит две функции для обработки списков банковских операций (словарей).

### 4. Модуль generators
Содержит три функции реализующие генераторы для обработки данных.

### 5. Модуль decorators
Содержит декоратор, который регистрирует детали выполнения функций.

### 6. Модуль utils
Содержит функцию, которая возвращает список словарей с данными о финансовых транзакциях.

### 7. Модуль external_api
Содержит функцию, которая принимает на вход транзакцию и возвращает сумму транзакции в рублях

### 8. Модуль file_readers
Содержит функции, которые считывают .csv и .xlsx файлы. 
Функции возвращают данные в виде списка словарей, что удобно для дальнейшей обработки и анализа данных.

## Тестирование

Для написания и запуска тестов используется фреймворк **`pytest`**. 

В процессе разработки тестов активно применяются лучшие практики:
- **Фикстуры (`@pytest.fixture`)** — для создания переиспользуемых наборов входных и ожидаемых данных, а также для подготовки тестового окружения.
- **Параметризация (`@pytest.mark.parametrize`)** — для проверки множества сценариев и граничных условий без дублирования кода.
- **Проверка исключений (`pytest.raises`)** — для гарантии корректной обработки невалидных данных и ошибок.
- **Мокирование (`Mock` и `patch`)** — для изоляции тестируемого кода и подмены внешних зависимостей. Это делает тесты быстрыми, надежными и независимыми от реального окружения.
  - *Примеры использования:* 
  - подмена функции `open` (`mock_open`) для тестирования чтения CSV/Excel без обращения к диску; 
  - подмена `requests.get` для тестирования запросов к внешнему API без реальных сетевых вызовов.

### Структура тестов

Тесты организованы в директории `tests/` и логически разделены по тестируемым модулям проекта:

```text
tests/
├── conftest.py          # Общие фикстуры, доступные для всех тестов
├── test_masks.py        # Тесты модуля masks 
├── test_widget.py       # Тесты модуля widget 
├── test_processing.py   # Тесты модуля processing 
├── test_generators.py   # Тесты модуля processing 
├── test_decorators.py   # Тесты модуля decorators 
├── test_utils.py        # Тесты модуля utils
├── test_external_api.py # Тесты модуля external_api
└── test_file_readers.py # Тесты модуля file_readers
```
